# T3 Nightly artwork

The three SVGs here come from T3 Code's Nightly app icon (`assets/nightly/app-icon.icon/Assets/` in pingdotgg/t3code, MIT). `../avatar-t3.mts` builds the T3 ball's living sky from them: clouds, stars, moon, aurora, storm. Motion runs on the avatar player's clock, and reduced-motion frames contain no autonomous animation.
