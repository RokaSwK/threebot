FAQ

Good questions.

What is Pingbot?

A messaging app for T3 Code. One long-lived thread becomes an agent you can text, and it runs your other threads for you. It keeps its own memory and can run things on a schedule.

How is it different from T3 Code?

T3 Code is built for running many coding agents at once. Pingbot sits on top of it and keeps things small: one or two agents you talk to about everyday things.

Where does it run?

On your own machine or server. Your agents, their memory and your saved logins all stay there. Nothing is hosted for you.

Can I use it?

Yes, if you run T3 Code. It's free and open source: clone the repository and follow the README.

Is this made by the T3 Code team?

No. Pingbot is an independent project built on T3 Code. It isn't affiliated with or endorsed by its team.
