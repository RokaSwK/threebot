Good questions

What is Threebot?

An app that gives a T3 Code thread a face, a memory and a place on your phone. You message it like a person, and it runs your other threads for you.

How is it different from T3 Code?

T3 Code is where threads run. Threebot sits on top of it and keeps things small: one or two Bots for each part of your life, each with its own thread, running the others.

Do I need another subscription?

No. Your Bots run on the Claude or Codex plan you already use with T3 Code. Threebot has no account of its own.

Where does it run?

On your own machine or server. Your Bots, their memory and your saved logins all stay there. Nothing is hosted for you.

Can I use it?

Soon. It will be free and open source, and you'll need T3 Code. The repository opens at launch.

Yes, if you run T3 Code. It's free and open source: clone the repository and follow the README.

Is this made by the T3 Code team?

No. Threebot is an independent project built on T3 Code. It isn't affiliated with or endorsed by its team.
